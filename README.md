# HiveGrid Energy

HiveGrid Energy, LLC is a Wyoming LLC with Texas foreign filing.

Public site: company marketing for residential battery-storage installation in Texas.
HiveGrid OS: the internal operating platform / online app (portal at `/portal`).

Cover line: One crew. One home. One standard.
Motto: “Building Trust Through Transparency”

## Current product boundaries

HiveGrid manages the residential battery installation path. It does not own or sell the batteries, does not operate battery-control software, and is not currently a VPP platform.

The portal is a protected Phase One demonstration. Its populated jobs are fictional sample data and are not connected to live project records. Live operational use begins only when the company is ready for first contracts and production authentication.

`/energy-calculator` is a legacy concept from an earlier VPP / consumer-sales direction. It is not a current HiveGrid service and must not be presented as one. The route is intentionally quarantined while the concept is retained in Git history for possible future use.
